# Deadzone County

เกมเอาตัวรอดซอมบี้ Co-op โลกถาวรสไตล์ **Project Zomboid** สร้างด้วย **Three.js + TypeScript + Node (`ws`)** สำหรับแพลตฟอร์ม **NAKALITE (`world` mode)**

## ฟีเจอร์หลัก
- **แผนที่ 480×480**: 4 ย่าน, อาคาร 52 แห่ง, จุดค้นของ 208 จุด และของตกพื้นเริ่มต้น 24 กอง (เน้นค้นของตามสถานที่) พร้อมขอบแผนที่ชนแบบล่องหน
- **โมเดลและท่าทาง**: ของในมือ/บนพื้นตรงชนิด แยกท่าฟัน แทง ยิง ผลัก ใช้อาหาร/ยา และสะดุ้งเมื่อเสีย HP
- **เซฟเก่าใช้ต่อได้**: คงย่านเดิมและเติมของในย่านใหม่ครั้งเดียว
- **โลกถาวร Co-op 2–8 คน**: เซฟตัวละครส่วนตัวและเซฟโลก (เข้าเซฟเจ้าของโลก) พร้อม `SaveQueue` ลงดิสก์, retry backoff, `saveKey` กันเซฟซ้ำ, และ `graceful shutdown`
- **เอาตัวรอดสไตล์ Project Zomboid**: ความหิว/กระหาย, สเตมิน่า, เลือดออก (ต้องพันแผล), อาการติดเชื้อเบื้องต้น (รักษาด้วยยาปฏิชีวนะ), ระดับความตื่นตระหนก (Moodles)
- **การลอบเร้น กรวยสายตา & เสียง**:
  - วิ่ง/ยิงปืน/ทุบสิ่งกีดขวางสร้างวงคลื่นเสียงดึงดูดซอมบี้
  - ย่อง (`C`) เพื่อลดเสียงและระยะตรวจจับ
  - กรวยสายตา + ระบบไฟฉาย (`F`) + กลางวัน/กลางคืน + ตัดหลังคาอาคารอัตโนมัติเมื่อเดินเข้าไปข้างใน
- **อาวุธ & การต่อสู้**: ไม้เบสบอล, ชะแลง, ขวานดับเพลิง, มีด, ปืนพก M9, ปืนลูกซอง JS-2000 พร้อมท่าผลักล้ม (`Space` / คลิกขวา)
- **ลูท & สร้างฐาน**: ค้นตู้ยา/ตู้เย็น/ล็อกเกอร์ปืน/ลังไม้/ท้ายรถ (`E`, ใช้เวลา 2–5 วินาที) แล้วเลือก Take 1 / Take stack / Take all, คราฟต์ผ้าพันแผล, สร้าง **Barricade**, **Campfire**, **Spike Trap** (`B`)
- **รองรับทั้ง PC และมือถือ**: Dual-stick บนหน้าจอสัมผัส

## คำสั่งรันพัฒนา
```bash
# Use Node.js 22 (Node 17 is unsupported)
npm install
npm run dev
```
เปิดทดสอบ 2 แท็บพร้อมกัน:
- แท็บ 1 (เจ้าของโลก): `http://localhost:5173/?world=dev#token=local:Kai`
- แท็บ 2 (ผู้เล่นคนที่ 2): `http://localhost:5173/?world=dev#token=local:Zed`

ทดสอบคำสั่งคุณภาพ:
```bash
npm run typecheck
npm test
npm run build
npm run check:save
npm run bots dev 2
```

## การค้นและเลือกหยิบของ
- กด E ใกล้ตู้หรือลัง แล้วยืนรอแถบค้นครบ; เดิน โจมตี โดนดาเมจ หรือกด E/Esc จะยกเลิก
- เลือกหยิบทีละชิ้น ทั้งกอง หรือทั้งหมด; ของที่ไม่หยิบ/ใส่กระเป๋าไม่พอยังคงอยู่ในตู้
- ตู้ที่ค้นแล้วเปิดดูได้ทันทีจนกว่าจะเติมของรอบใหม่ ผู้เล่น Co-op เห็นของคงเหลือร่วมกัน
- โลกใหม่มีของตกพื้น 24 กอง ส่วนของตกพื้นในเซฟเดิมยังคงอยู่ ไม่ลบของที่ผู้เล่นเคยทิ้งไว้
